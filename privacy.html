Privacy Policy

Last updated: October 17, 2026

Purpose and scope

Health-research-site is a private, non-commercial application operated by its owner for accessing and analyzing the owner's own Oura account data. It is not a public service and does not register other users.

Data accessed

With account authorization, the local application may retrieve health and activity data, including sleep, heart rate, heart-rate variability, temperature-related summaries and blood oxygen saturation results, depending on the permissions granted and data made available by the Oura API.

Storage, use and sharing

Downloaded account data are used for the owner's personal analysis and, in the current local-only configuration, are stored on the owner's computer. The website itself does not receive or host Oura health records. The application does not sell data or provide a third-party account service.

API access tokens are intended to remain in local application storage and are not published on this website or in the site's source repository. The owner can delete locally stored exports and revoke application authorization through the relevant account controls.

Website hosting

This informational website is hosted by GitHub Pages. It does not intentionally set application analytics cookies, collect health information through forms, or run advertising scripts. GitHub may process technical access information under its own policies.
